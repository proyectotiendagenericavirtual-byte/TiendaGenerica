# Proyecto Tienda Genérica — Demo GitHub Pages

App de demostración: login, usuarios, clientes, proveedores, productos
(carga CSV), ventas (con IVA) y reportes — funciona 100% en el navegador,
sin backend ni AWS. Los datos se guardan en localStorage.

Para probar la carga de productos usa el archivo
`database_productos_muestra.csv` de este repositorio.

Hay un botón "Restablecer datos de la demo" en el menú principal.
